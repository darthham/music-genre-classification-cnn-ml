## 1. Problem Statement
Music genre classification automatically assigns an audio track to a genre. Manual organization of large music collections is time-consuming, while genre boundaries can be ambiguous. This project investigates whether learned representations from a Dilated Convolutional Neural Network (DCNN) can improve classical classifiers.

## 2. Dataset
The reference paper uses the GTZAN dataset. It selects five genres—classical, hiphop, metal, pop, and blues—with 100 tracks per genre (500 tracks total). Each track is 30 seconds long. The paper reports an 80:20 train/test split. In this implementation, the actual number of successfully processed files and split counts are recorded in `artifacts/features/metadata.json`.

## 3. Methodology
Audio is loaded as mono at 22,050 Hz. Librosa extracts 20 MFCC coefficients, represented as a time-by-feature sequence. A two-block 1D Dilated CNN learns audio representations. The activations from both convolutional blocks are pooled to form feature vectors. Four classical classifiers—Logistic Regression, RBF SVM, Random Forest, and Linear Discriminant Analysis (used as a shared-covariance GDA-style classifier)—are trained on raw MFCC, PCA-reduced MFCC, and CNN-derived features.

## 4. Implementation
The implementation is organized into separate modules for MFCC extraction, CNN architecture, CNN training, and classical model evaluation. A fixed train/test split is reused across experiments. Feature normalization and PCA are fitted using training data only to avoid test-set leakage. Evaluation includes accuracy, classification reports, and confusion matrices.
